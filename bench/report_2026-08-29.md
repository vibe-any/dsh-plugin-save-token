## TL;DR

6 个高输出任务（GAIA locomotives / GAIA arxiv-regulation / TB access-logs /
TB jsonl-aggregator / SWE sympy-24562 / SWE django-16595）× 2 臂 × n=2，
24/24 集有效：

- **总 Token −17.6%**（5,245,583 → 4,322,979，净省 922,604）
- **成功率零损伤**（两臂均 100%，ΔSR +0.0pp）
- 压缩**触发 16 次**，覆盖 8/12 个 treatment 集；单集 Token 中位数 **−56%**（474,108 → 205,982）

**给使用者的判据**：当工作负载会把大块结构化输出（日志、JSON 响应、详细测试输出）
直接送进上下文时，插件有实际净收益且不损失任务成功率；当 agent 走「写文件 + 定点读取」
路线时，插件不触发、也无代价（read 类工具被设计豁免）。

## 方法

- **行为条件**：两臂对称施加 `HARD CONSTRAINTS`（禁文件重定向、禁用 read 工具
  批量查看、测试输出必须可见），把 agent 行为推进「大输出直出」区间。该条件使
  插件触发面存在——本实验测量的是「直出型工作负载下的插件价值」；自然行为下
  agent 惯用「写中间文件 → read 定点查看 → 只打印摘要」路线，恰好完整绕开触发链。
- **臂**：`baseline` = 插件压缩/去重关；`treatment` = 开。每格 n=2。
- **有效性控制**：判定脚本经金解 3/3 正向 + 阴性对照校准；无效集（路由中途死亡、
  答案漂移、启动崩溃）一律重发或弃档并留痕（本阶段弃档 1 次，不计档）；
  GAIA 票房题在预实验中因实时榜单答案漂移换为稳定题（见 manifest `replacement_note`）。

## 触发边界（机制归因）

插件触发链：**顶层工具 + 非 read + 纯文本结果 + >1400B + JSON/行结构可压 + 省 ≥500B**。
本实验的 HARD CONSTRAINTS 就是把行为推回该触发面的最小干预——反面即：默认
agent 习惯（写中间文件 → read 定点查看；`pytest -q` 摘要输出；脚本化计算后只打印
结论）会自然绕开压缩，此时插件静默、零开销。两条使用建议：

1. 让大输出**直出**（打印而非落盘、测试带全量输出）时插件收益最大；
2. 输出天然小于阈值的任务（如本组 TB jsonl）无触发即无收益，属预期行为。

## 局限

- n=2 无显著性检验；路由非确定性对两臂对称，但单格行为方差可达 ±3 倍（见逐集明细），
  逐任务 Δ 必须配对解读。
- 约束文本在首集后补入「禁 read 批量查看」一行（关闭 read 豁免漏洞），用于其后
  全部 treatment 集；baseline 各集在原文本下已实证合规（巨型 bash 直出在案）。
- `avoidedTokens` 为插件回放估计，仅作旁证；净节省以同格 Token 差额为准。
- GAIA 题存在公开基准污染（agent 可检索到金标），两臂对称暴露，不影响 A/B 差分。
- SWE/TB 为原生 macOS 复刻（非官方 Docker），判定与官方同口径。
